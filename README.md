# SSAT Climb

Offline-first iPhone web app for SSAT Upper Level verbal practice: synonyms, analogies (bridge first), and a personal word list with quick-add from any screen.

- Open the site in Safari → Share → **Add to Home Screen**. Use it from the home-screen icon; after the first load it works offline.
- Progress is stored only on the device. Use Progress → Parent tools to export a backup.
- Added words are looked up online (dictionaryapi.dev, Datamuse) when a connection is available.

All questions, definitions and examples are original.
